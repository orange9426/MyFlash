# MyFlash

楼道暴露挑战 — 基于网页的冒险游戏。玩家需要在楼道中向上攀爬，完成随机生成的挑战任务，管理积分和物品，最终根据得分达成不同的结局。

部署后访问：`https://你的GitHub用户名.github.io/MyFlash/`。此地址需替换用户名，并完成下方部署步骤后才能使用。

本项目基于 StaircaseTrial 修改，保留原有 GPL-3.0 许可证和作者信息。

## 本版任务系统

- 任务已按角色、模式拆分到 `src/lib/game/tasks/`，编辑方法见 [任务配置说明](docs/TASK_CONFIGURATION.md)。
- 每项任务在同一个对象中配置 `description` 和 `needs`，不再维护按任务 ID 分离的装备需求表。
- 装备包含鞋子（商店 2 积分，可退货，计入积分加成和随机移除）；已移除护膝选项、穿戴指示及依赖护膝的任务。
- 固定连续 6 层（默认 1–6 层；修改起始层只平移楼层编号）。每层从当前角色和难度的楼层任务池抽取两个不同候选，选定并完成其中一个。配置仅保留“楼层任务”和“上楼任务”两个数组。
- 每层任务后只上 1 层，路线为 1→2→3→4→5→6。共 6 个楼层任务和 5 次上楼，11 个进度步骤；完成或跳过最后一层任务后结算。
- 普通、地狱模式使用相同路线，保留模式的计分与随机事件差异；不再安排第八层双任务或额外电梯厅楼层。原有结局分数阈值暂不调整。
- 每局提供 2 次免费刷新候选的机会，两张任务卡共用额度；每张卡可单独刷新或确认，确认后不能刷新。不扣积分、不消耗道具、不推进进度。
- 免费更换从同一角色和难度的合并池抽取不同任务，满足必需装备条件，优先避开全程计划中的其他任务。
- 候选不足时允许使用计划中的任务，但不会抽回当前任务或本局被换掉的任务。
- 上楼任务不参与更换。更换结果、已用次数自动保存；路线版本更新后直接新开局，不迁移旧进度。同版本内刷新可继续游戏。
- 上楼任务中的距离文案统一为一层；商品价格与任务计分公式保持原样。最终层任务后直接结算。

## 手机调试

电脑与手机连接同一个 Wi-Fi，执行 `npm run dev -- --host 0.0.0.0`。
手机访问 `http://电脑的局域网IP:5173/MyFlash/`，端口以终端实际显示为准。
电脑需保持运行，必要时允许 Node.js 通过 Windows 专用网络防火墙。

## 功能特性

- **爬楼机制**：从第 1 层开始，逐层向上挑战
- **随机任务系统**：楼内任务与上楼任务交替推进
- **积分系统**：根据任务完成情况、穿着状态等计算得分
- **商店系统**：购买衣物和道具（跳过任务券、恢复内裤券）
- **物品库存**：管理和使用购买的道具
- **多结局判定**：根据最终得分决定不同的游戏结局
- **本地存档**：自动保存游戏进度与历史记录（最多 10 条）
- **响应式界面**：基于 shadcn/ui 的现代暗色主题 UI
